AEP - PSE - Sistema de Planejamento e Acompanhamento de Ações de Saúde na Escola

Nome dos Integrantes: Daniel Machado Gonçalves e Pedro Henrique Macedo Guedes

Engenharia de Software

Objetivo do programa: Desenvolver um sistema em linguagem C, executado via terminal, que permita a uma equipe intersetorial do PSE cadastrar, listar, pesquisar, atualizar e acompanhar, por meio de resumos consolidados, as ações de saúde planejadas e realizadas nas escolas participantes do programa.
